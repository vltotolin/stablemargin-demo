# StableMargin: демонстрационный прототип для Академии Финтеха ВТБ

**Команда «Дихотомия»**. Рабочий учебный прототип первого спринта. Версия публикации 1.1: исправлена обработка пустых числовых полей.

## Что это такое

StableMargin анализирует параметры будущей закупки и показывает, может ли в заданном **условном сценарии** фьючерсная позиция ограничить снижение маржи предприятия с учётом денежного резерва. Возможные результаты: «условная стратегия», «защита не требуется», «нет допустимого решения» и «недостаточно данных».

Это **не торговая система**. Нет биржевых котировок, счёта у брокера, банковской интеграции и автоматического исполнения сделок. Проверки закупки, базиса, ликвидности и актуальности котировки в интерфейсе являются **ручными учебными переключателями**, а не фактически подключёнными внешними проверками. Динамика цены фьючерса вводится как сценарий, а не прогнозируется.

## Как открыть

Откройте `index.html` в браузере либо используйте ссылку на опубликованный GitHub Pages сайт, если владелец репозитория включил публикацию.

## Что показать жюри

1. Откройте пример «Какао». При условных данных получается **17 контрактов** с денежным резервом 43 082,93 ₽ и результатом партии 15 205,20 ₽.
2. Выберите «Строгий лимит». Защита блокируется, поскольку нет количества контрактов, которое одновременно выполнит требования к марже и резерву.
3. Выберите «Нет связи цен». Система не предлагает сделку без подтверждённой связи закупочной и биржевой цен.
4. Выберите «Импорт за юани» для просмотра отдельного валютного сценария, параметры которого учебные.
5. Измените любое поле, чтобы увидеть перерасчёт; попробуйте кнопки экспорта JSON и CSV.

## Какие файлы здесь лежат

- `index.html`: страница, которую видит пользователь.
- `styles.css`: цвета, размеры и расположение элементов.
- `core.js`: расчётные правила и примеры закупок.
- `app.js`: реакция на ввод пользователя и выгрузка результатов.
- `core.test.js`: автоматические проверки расчётного ядра (запуск необязателен для просмотра демо).

Для дополнительной технической проверки при наличии Node.js 18+ выполните `node --test core.test.js`.

## Что осталось до реального внедрения

Нужны первичные данные реальных закупок, независимая проверка связи цен, автоматические актуальные биржевые данные, модель денежного клиринга, подтверждение финансовых выводов специалистами, согласование правовой модели и только после этого банковский пилот.

Программа работает на стороне браузера, не отправляет параметры закупок на сервер приложения. **Не вводите реальные конфиденциальные данные в публичное демо.**

## Публикация без установки программ

1. Создайте публичный репозиторий на GitHub.
2. Загрузите **в корень** репозитория все шесть файлов: `index.html`, `core.js`, `app.js`, `styles.css`, `core.test.js`, `README.md`. Не загружайте ZIP как один файл.
3. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, каталог **/(root)** и сохраните.
4. Для анкеты понадобятся две разные ссылки: адрес репозитория с исходным кодом и адрес опубликованного сайта из вкладки **Pages**.
5. Перед сдачей откройте ссылку сайта в приватном окне браузера и проверьте сценарии и выгрузку.

Адрес опубликованного сайта создаётся GitHub после настройки; этот архив не содержит готовой ссылки.
